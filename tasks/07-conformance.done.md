## Intended differences (normalised in `verify/conform/intended.lua`, listed in `verify/features/conformance.md` and `docs/usage.md`)

1. Missing path label: Lua `InvalidInput` before sending; Distilled sends `{project_id}` literally.
2. `err.status` on typed and status-mapped errors: always set in Lua; absent in Distilled.
3. `err.code`: wire code or nil in Lua; `0` on Distilled's generated classes, absent on its built-ins.
4. Parse error message: descriptive in Lua; `""` in Distilled.
5. Transport failure: `TransportError` + `NetworkError` in Lua; Effect's `HttpClientError`.
6. asctime `Retry-After`: GMT in Lua; Distilled's `Date.parse` uses the machine's zone (18010 s instead of 10 s here). This one is arguably a Distilled bug.

Not a difference but modelled: multipart parts are compared after applying undici's
FormData serialization (CRLF in text values, `application/octet-stream` for a typeless
file), because Distilled's request holds an unserialized `FormData`.

- **Jaeger round trip**: the Docker daemon is not running (`dl jaeger check` exit 3);

  no budget and never stops, so there is no reference outcome.

## Where the code differs from the plan (the docs describe the code)

- Plan: `transport = require("distilled.transport.popen_curl")`. The module is a
  constructor: the transport is `popen_curl()` (called). The docs use
  `host = require("distilled.host.popen")()`.
- Plan's span attribute `distilled.retry.attempts` is `distilled.attempts` (Distilled's
  telemetry name); `distilled.retry.stopped` and `distilled.pagination.*` are additions.
- Plan's provider spec (`base_url = "..."`, `auth = {...}`) gained `base_url = { default,
  option, env }`, `unknown_tag`, `parse_tag`, `naming`, `pagination`.
- `distilled-lua vendor` copies only the runtime; the client is written by `generate --out`
  into the same tree.
- Traces are flushed when each outermost call returns (not at `client:close()` or per
  scope), which answers the plan's open question for Rex.
- With `distilled.host.popen`, `now` is `os.time`, so deadlines and span durations are in
  whole seconds (the plan's default too).
- `err.code` is the wire code or nil (Distilled: `0`), `err.status` is always set.
