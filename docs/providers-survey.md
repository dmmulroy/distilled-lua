# Provider survey (task 13)

What each Distilled REST package writes by hand (`src/credentials.ts`, `src/protocol.ts`,
`src/errors.ts`, sometimes `pagination.ts` and `scripts/generate.ts`), and whether a
distilled-lua provider spec can say it. Surveyed from `../distilled/packages` at the time
of task 13: every package except aws, aws4signer, s3, azure, gcp, google-workspace,
cloudflare, tencentcloud, core, dev and the GraphQL ones (linear, railway, expo-eas).
106 packages.

Classes:

- **A**: expressible with the spec as it was before task 13 (bearer or one header, one
  base URL with one environment variable, a `{ code, message }` envelope, a status map).
- **B**: needs a spec feature task 13 added (below), sometimes with a small hand-written
  glue module (`providers/glue/<name>.lua`).
- **C**: needs crypto or signing (task 14) or another protocol.

| B | 83 (79 written; hetzner is task 10's; questrade, scaleway and slack are not written, reasons in their rows) |
| C | 5 |

## Features added for class B (`docs/generating.md` section 4)

| Feature | Spec key | Packages (examples) |
| --- | --- | --- |
| Environment fallbacks (`A ?? B ?? C`) | `env = { "A", "B" }` on auth, base_url, options | axiom, sentry, digitalocean, spacetimedb, gusto |
| Extra options (versions, regions, org ids) | `options = { name = { env, default, secret, required, ... } }` | anthropic, notion, intercom, whop, plaid |
| Option and fixed headers, omitted when unset | `headers = { ["X-Name"] = "{option}" }` | X-Axiom-Org-ID, Clerk-API-Version, X-GitHub-Api-Version, API-Version: 2 |
| Several secret headers | `headers` with secret options | porkbun, redis-cloud, datadog, plaid |
| Auth prefixes | `auth.prefix` (kind `header`) | `token ` (forgejo), `ApiKey ` (elasticsearch, zerossl), `Token ` (netbird) |
| Basic auth | `auth = { kind = "basic", username, password }`, `{ basic = "{a}:{b}" }` header values | clickhouse-cloud, opencode, mailchimp, zendesk, opensearch |
| Optional auth | `auth.optional = true` | docker, infisical, npm, iceberg, modrinth, spacetimedb |
| Alternative credentials | header value lists (first that renders wins), `require_one_of` | planetscale, zendesk, e2b, opensearch |
| Public operations | `public_operations = { "Op" }` | doppler |
| Required base URL | `base_url` without `default` | kubernetes, typesense, forgejo, okta, celld |
| Templated base URL | `base_url.default = "https://api.{site}"` | datadog, auth0, dokploy, e2b, mailchimp |
| Choices (environment to URL) | `options.x.choices`, `ignore_case`, `invalid = "default"` | archil, coinflow, ovh, plaid, discord, okta |
| Trim, suffix, origin rules | `trim_slash`, `strip_scheme`, `ensure_suffix`, `origin = { label, example, bare_host }` | npm, grafana, forgejo, tailscale, netbird, technitium, starburst-galaxy |
| User-Agent | `user_agent = { default, env }` | github, modrinth, squarespace, resend |
| Envelope fallbacks | `error_envelope = { code = { ... }, message = { ... }, non_empty }` | customerio, datadog, posthog, unkey, hydradb |
| Status classes the shared map lacks | `error_classes` + `status_map` | 402, 405, 408, 410, 412, 413, 416, 419, 421, 424, 428 (529 is the built-in ServiceUnavailable) |
| Unknown-error fields | `unknown_fields = { reason = "/reason" }` | kubernetes, prisma, discord, namespacelabs, mongodb-atlas, stripe |
| Response transforms | `transform_response = { "strip_nulls", { unwrap = "result", skip_paginated = true } }` | axiom, daytona, clickhouse-cloud, proxmox |
| OAuth 2.0 client credentials | `oauth = { token_url, client_id, client_secret, into, auth, scope, extra, reuse, exclusive }` | mongodb-atlas, starburst-galaxy, tailscale (onepassword users: per-model) |
| Bodies for member-less operations | `empty_json_body = true` | namespacelabs (e2b envd) |
| Bracket query style | `query_style = "brackets"` | stripe |
| Hand-written glue | `glue = "glue/<name>.lua"`: settings, base_url, headers, transform_input, error_envelope, classify_error, classify_success, transform_response, unknown_error | per-route base URLs (s2, daytona, iceberg, inngest, namespacelabs, stackit, digitalocean), derived settings (mailchimp, rivet, zendesk, chronosphere, fly-io, onepassword, proxmox), rate-limit readers (github, starburst-galaxy), in-band failures (zerossl, technitium), error families (stripe, supabase, entire, celld) |

## Cross-task dependencies

- **Task 10 (per-model overrides)**: clerk, convex, digitalocean, e2b, exa, fly-io,
  mailchimp and onepassword have models with *different auth* (their rows). The specs cover
  the primary model; the others need `models.override` to carry `auth`, `options` and
  `headers`, not only `title` and `base_url`. entire's Core models need only a
  `base_url` override (`option = "core_base_url"`).
- **Task 12 (per-operation base URL)**: stackit (http-trait `baseUrl` + region) and
  digitalocean (`server`) read `route.server` in their glue; mongodb-atlas needs the http
  trait's `accept`; boat-dev has streaming operations; render, polar, resend, revenuecat,
  s2 and stripe have custom pagination.
- **Task 14 (signing)**: the C rows, opensearch's SigV4 path, github App auth (RS256 JWT).
