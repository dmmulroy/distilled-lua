Generate a Web Application Firewall (WAF) to use with Application Load Balancers (ALB). The name of the WAF configuration is used in the listener of the ALB. This will activate the WAF for that listener. A WAF can have a Managed Rule Set (MRS) and or a Custom Rule Group (CRG). To create a WAF one first needs to create all the configurations that are referenced in the WAF configuration. Once all configurations are created and referenced in the WAF configuration it can be used with an ALB.
