A port of Distilled's `Eas` GraphQL SDK (`graphql-client.ts` output). Roots

| --- | --- |
| `access_token` | secret (a string, a secret, or `fn(host) -> value, err`), sent as `Authorization: Bearer <token>`; default from `EXPO_TOKEN` |
| `base_url` | API base URL, default `https://api.expo.dev` or `$EXPO_API_URL`; the endpoint is the base + `/graphql` |

With no credential at all a run fails with `ConfigError`: EXPO_TOKEN environment variable is required.

## Run

```lua
local value, err = client:run(Eas.account())
```

Combinators: `gql.map(q, fn)`, `gql.filter(q, fn)`, `gql.flat_map(q, fn)`, `gql.of(v)`,
`gql.fn(build)`. GraphQL names stay as the schema spells them (`issueCreate`,
`avatarUrl`), in Queries and in the values a run returns. A field that takes arguments
is called with a table: `account.byId({ accountId = id })`. Sensitive fields come back
as `distilled.secret` values. Mutations are never retried; queries are retried (at most
5 times, 200 ms doubling) while every error is retryable.
