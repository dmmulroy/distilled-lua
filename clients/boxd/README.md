## Wire and options

gRPC-Web (`distilled.protocol.grpc`): each operation is one protobuf frame, transcoded with
`descriptors.lua`. Server-streaming operations return `{ items = { ... } }`, the whole
stream collected from one response.

| Option | Meaning |
| --- | --- |
| `base_url` | value; default `https://boxd.sh:9443`; or from `BOXD_BASE_URL`, then `BOXD_API_URL` |
| `token` | required secret: an API key (bxd_...) or a session token, sent as the bearer; or from `BOXD_API_KEY`, then `BOXD_TOKEN` |
