### Read this before writing code (gopher-lua facts, measured in Rex)

- **Never use plain `pcall` in library code.** In gopher-lua a `pcall` that catches an
  error breaks the upvalues of closures created earlier in any running frame (they keep
  writing to a stale copy). `compat.pcall(fn, ...)` is built on `xpcall` and is safe. In
  specs use `t.pcall(fn)`. This bug made `spec/run.lua` print `ok` after a failure before
  it was fixed (counters now live in a table).
- `error(msg, 2)` reports at level 1 in gopher-lua. Use `compat.raise(msg, 2)` when the
  position matters (`distilled.check` does).
- `table.concat` raises "registry overflow" past ~2,500 items: use `compat.concat`.
- Call stack ~250 frames: no recursion over data depth (json and `secret.unwrap_deep` use
  explicit stacks). `t.same` recurses, so compare very deep data by encoded string.
- `math.huge` is the largest finite double; use `1/0` for infinity.
- `tonumber` rejects `"1e5"`, big digit strings and out-of-range numbers (nil); use
  `json.decode` for wire numbers.
- Weak tables are never collected. `string.format("%s", t)` ignores `__tostring`.
- `rex do` script: `debug.getinfo(1, "S").source` is the absolute path (no `@`);
  `rex.args` holds `key=value` arguments; `error(...)` exits 1 with `Error: <msg>`;
  `os.exit(n)` works too; `print` goes to stdout.

## 02 trace

**Done.** Tracer, noop tracer, OTLP/JSON, memory/file/console exporters, tree, golden

### Read this before writing code

- **A second gopher-lua upvalue bug: nested protected calls.** Once a `pcall` or `xpcall`
  has *completed* inside another protected call, the outer one catching an error breaks
  the upvalues of closures in running frames, exactly like the plain-pcall bug. So
  `compat.pcall` (xpcall) is **not** safe when nested: `xpcall(function() xpcall(f, h);
  error("y") end, h)` leaves a counter closure writing to a stale copy (measured in Rex,
  `/tmp`-style repros in the done file). A coroutine that catches the error is not
  affected. **Fixed in the follow-up:** `compat.pcall` is now built on a coroutine.
- A script for `dl trace`/`dl expect` reaches its tracer with
  `require("verify.lib.trace_env")` (`env.tracer`, `env.host`, `env.spans()`,
  `env.expect()`); `dl expect` calls a function the script returns with `expect(spans)`.
- For specs: `verify/lib/trace_fake_host.lua` (fixed epoch, fake clock, seeded random)
  and `distilled.trace.expect` over `trace.exporters.memory()`.

### Decisions / proposed contract updates (`docs/interfaces.md`, Tracer)

- Exporters are called as `exporter(spans, meta)` with `meta = { service_name }`, so the
  file/otlp exporters can fill `resource.service.name`. Extra argument, compatible.
- `memory()` is a callable table (`.spans`, `:clear()`), so exporters are "callable", not
  always functions; `trace.new` accepts either.
- `kind` defaults to `"internal"`; also accepts `"server"`. Status stays `"unset"` on
  success (OTel guidance for libraries); only failures set `"error"`.
- `span:fail(err)` sets `status.message = err.message` and `error.type = err.tag`
  (`"_OTHER"` without a tag, as Distilled's `tagOf`). `tracer:with` does **not** set
  `err.trace_id`; the operation layer (task 04) should do that.
- Finishing a span ends any children still open under it (a raise skipped their finish).
- Each root span starts a new trace unless `parent` is given; then every root continues it.
- `traceparent()` returns nil when no span is open, even with an incoming `parent`.
- Flush failures are `SdkError` "trace export failed: ...". Exported spans are in start
  order. Extra exports: `trace.NOOP_SPAN`, `trace.parse_traceparent`, `trace.ns_diff_ms`,
  `trace.attribute_value`, `trace.tag_of`.
- `trace.noop` is `distilled.trace.noop` (see the follow-up below).

### Follow-up (after verification)

**Done.** `compat.pcall` is rebuilt on a coroutine (same signature, same results); the
tracer, `Scope` and the harness all go through it; the noop tracer is its own module.

- **`compat.pcall(fn, ...)`** runs fn in a coroutine. It is safe from both gopher-lua
  upvalue bugs at any nesting depth, and yield-transparent: a yield inside fn goes to the
  coroutine that called compat.pcall and the resume values come back. Outside any
  coroutine a yield returns `false, "attempt to yield from outside a coroutine"`. When
  nested, the yield travels out to the outermost compat.pcall, which reports it (native
  `pcall(pcall, coroutine.yield)` would have the innermost one catch it instead).
  It accepts C functions and callable tables. The `ERROR_LEVEL_SHIFT` probe now runs in a
  coroutine too.
- **Limit (all runtimes, not caused by compat.pcall):** a yield cannot cross a C/Go call
  boundary such as a `table.sort` comparator or a `string.gsub` callback. lua/luajit
  raise "attempt to yield across a C-call boundary". **gopher-lua crashes the whole run**
  ("invalid memory address or nil pointer dereference"), with or without compat.pcall.
- **Changed behaviour others may notice:** code under compat.pcall sees a different
  `coroutine.running()`. A raise keeps its message and position, but a traceback taken
  later only covers the stack from the re-raise.
  `debug.traceback` must not be called through compat.pcall (that would trace the
  coroutine's stack); the harness now calls it directly in its handler.
- `Scope.with`, `scope:close` and `scope:defer` needed no change (they already call
  compat.pcall). The harness `t.pcall` / `t.raises` / `t.describe` use compat.pcall.
  `t._run` keeps one outermost `xpcall` for its traceback handler, which is safe because
  nothing nested inside it uses xpcall.
- `lua/distilled/trace/noop.lua` requires nothing. `distilled.trace` re-exports it
  (`trace.noop` is the same object, `trace.NOOP_SPAN`). A spec checks that requiring it
  loads only that module.
- Regression specs in `spec/compat_spec.lua` (11 new). With the old xpcall-based
  compat.pcall swapped back in, 9 of them fail under Rex.
- `verify/features/README.md` lists tracing.md and both bugs, plus the yield crash;
  `verify/features/scope.md` is updated.

### Decisions others should know

- `request.build` args beyond the contract: `map_member_header(name, value)`,
  `unknown_key_to_wire(key)`, `empty_json_body`, `query_style = "brackets"` (Distilled's
  protocol options; the REST protocol passes them through).
- `op.body_media_type` (Distilled's `bodyMediaType`): with it, or with a `blob` payload
  schema, a string `payload` is sent raw; otherwise a payload is JSON.
- Any schema node may carry `sensitive = true` (Smithy puts `@sensitive` on shapes; list
  items and map values have no member). `schema.node_sensitive` reads it through refs.
- `redact.plain(node, text, registry)` and `redact.parsed(node, value, registry)` (logs).
- `validate.check` mismatch: `{ path, expected, actual, missing, message }`; list indices
  in paths are 1-based. `validate.withhold(m)` for parse errors that withhold the body.
- A missing label is `InvalidInput` (Distilled sends `{name}` literally). A header value
  with CR/LF is `InvalidInput`.
- `keys` on decode never drops keys of inactive union arms (Distilled's `UnionCases`
  does; the node contract cannot tell a merged-case union from a Smithy union).
- `testing.transport{ responses }` is a callable table (`tr(req)`), not a function; it
  raises when it runs out. `testing.host{}` adds `sleeps`, `clock`, `advance(s)`,
  `requests`. `testing.random(seed)` is Park-Miller, identical on all runtimes.
- `regex.compile` errors are `SdkError` tables; `errors._regex_cache[source]` holds the
  compiled matcher or `false`.
