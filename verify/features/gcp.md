# GCP and Google Workspace (`clients/gcp`, `clients/google_workspace`, `distilled.gcp.*`)

Task 21. Ports `../distilled/packages/gcp/src/` and `../distilled/packages/google-workspace/src/`.

## Sub-features

- **Models.** `verify/dl models sync` copies `.generated-specs/stable/*.json` to
  `models/<pkg>/` and `.generated-specs/unstable/*.json` to `models/<pkg>/unstable/`
  (gcp: 315 + 214, google-workspace: 28 + 7). `bin/distilled-lua package` generates
  `<models>/unstable/` into `<out>/unstable/<model>/` as `<pkg>.unstable.<model>`, with
  its own index. This mirrors `@distilled.cloud/gcp/<service>` and its unstable entry.
- **Discovery models** (`lua/distilled/gen/discovery.lua`, turned on by `discovery = {
  error_matchers = <trait> }` in the provider spec): the relative `v1/{+name}` URIs become
  `/v1/{name+}` (a greedy label, sent with reserved expansion), a structure `httpPayload`
  body is flattened into top-level input members (labels and query members win on a name
  clash, as in Distilled's codegen), each model's `metadata.baseUrl` is the service's base
  URL, and the `com.gcp.protocols#errorMatchers` / `com.googleworkspace.protocols#errorMatchers`
  traits become typed error matchers (`status`, `message.includes`, `message.matches`).
  Operation names drop a trailing `_` (`Delete_` → `delete`).
- **Protocol** (`distilled.gcp.protocol`; Workspace: `distilled.gcp.workspace`):
  - credentials are resolved on every attempt (so a retried request carries a refreshed
    token): `credentials` option → `access_token` option → `GOOGLE_ACCESS_TOKEN` →
    Application Default Credentials (one ADC provider per client; GCP only);
  - `Authorization: Bearer <token>`; `X-Goog-User-Project` from `quota_project`, else the
    credentials' (GCP only, as Distilled);
  - path labels: plain ones fully percent-encoded, `{+name}` keeps `/` and RFC 6570
    reserved characters; query arrays repeated; JSON body only when a body member is set;
    header members (`x-goog-request-params`) lower-cased;
  - endpoints: `endpoint` option or `GOOGLE_API_ENDPOINT` replaces the origin and keeps the
    service path (and wins over regional routing); `regional_endpoints` = `required`
    (default; Vertex AI, Secret Manager, Parameter Manager go to the location's host),
    `prefer` (any service Google publishes a regional host for,
    `lua/distilled/gcp/regional_endpoints.lua`, generated by
    `verify/lib/gcp_regional_endpoints.mjs` from Distilled's table) or `never`; global,
    `-` and unpublished locations stay global;
  - errors: the `{ error: { code, status, message, details } }` envelope is matched against
    the operation's typed errors (message matchers before bare status ones), then the
    status map, then any 5xx is `InternalServerError`, else `UnknownGCPError` /
    `UnknownGoogleWorkspaceError` (`status` = HTTP status, `code` = envelope status). Typed
    errors carry `code`, `message`, `details`, and the envelope status as `rpc_status`
    (Distilled: `status`; in Lua `status` is the HTTP status). Non-JSON bodies become the
    message; an empty or envelope-less body uses the HTTP status. Parse failures under
    `validation = "strict"` are `GCPParseError` / `GoogleWorkspaceParseError`.
  - pagination: `pageToken` → `nextPageToken`; operations whose trait names no items path
    page through whole pages (`items` yields each page).
- **Credentials** (`distilled.gcp.credentials`): `from_access_token`, `from_env`,
  `from_authorized_user` (refresh-token grant), `from_service_account_key` (RS256 JWT
  assertion through `distilled.crypto.jwt` of task 24, byte-identical to Distilled's),
  `from_metadata_server` (`Metadata-Flavor: Google`, project id), `from_workload_identity`
  (STS token exchange, optional impersonation), `from_application_default`
  (`GOOGLE_APPLICATION_CREDENTIALS`, gcloud's file, then the metadata server; file types
  `authorized_user`, `service_account`, `external_account` with file or URL sources,
  `impersonated_service_account`), `custom(fn)`. Tokens are cached and refreshed five
  minutes before expiry. Project and quota project: options, then env
  (`GOOGLE_CLOUD_PROJECT`, `GCLOUD_PROJECT`, `GOOGLE_PROJECT_ID`,
  `GOOGLE_CLOUD_QUOTA_PROJECT`), then the file.
- **Retry**: Google's per-method retry configs are model traits; the generated ops carry
  them (`retry = { max_attempts = 1 }` for non-idempotent ones).

## How a user reaches it

```lua
local creds = require("distilled.gcp.credentials")
local Storage = require("gcp.storage_v1")
local s = Storage.new({ host = host, credentials = creds.from_application_default() })
for bucket in s:list_buckets_items({ project = "my-project" }) do print(bucket.name) end

local Vertex = require("gcp.aiplatform_v1")       -- us-central1-aiplatform.googleapis.com
local Beta = require("gcp.unstable.compute_beta") -- unstable models
local Gmail = require("google_workspace.gmail_v1")
Gmail.new({ host = host, access_token = token }):list_users_messages({ userId = "me" })
```

## Driving it with `dl`

- `verify/dl gen-diff gcp` / `verify/dl gen-diff google-workspace`: generation is
  reproducible (lua = luajit, committed tree = fresh), every service loads and builds
  every request in lua, luajit and Rex (31288 + 1021 ops), and `verify/lib/gcp_check.lua`
  encodes every op through the package's protocol.
- `verify/dl test gcp_protocol_spec`: Distilled's `protocol.test.ts` for both packages,
  plus retries with credentials per attempt, `GOOGLE_API_ENDPOINT`, option misuse.
- `verify/dl test gcp_credentials_spec`: Distilled's credential-provider tests (ADC file
  types, metadata server, workload identity, refresh window, no secret in errors), the
  RS256 assertion against task 24's golden token, verified with the public key.
- `verify/dl test gcp_conform_spec`: 1078 requests (two ops per model, every stable and
  unstable gcp and workspace model, plus hand cases for options and bindings), 26
  responses and 3 pagination flows compared with what Distilled's TypeScript does
  (`spec/golden/gcp/reference.json`). Regenerate with
  `lua verify/lib/gcp_conform_cases.lua "$PWD"` then
  `node --conditions=bun --experimental-transform-types --no-warnings verify/lib/gcp_conform.mjs`.

## Gotchas

- A message matcher in a typed error with a separate status-only matcher
  (`{ {status = 429}, {message = ...} }`) is two alternatives, not one conjunction: a
  plain 429 matches `ServiceAccountQuotaExceeded` too (Distilled does the same).
- Distilled's error view reports `throttling` only for a *retryable* throttle; Lua's
  `err.throttling` is true for any ThrottlingError. The conform spec compares the former.
- No `User-Agent` is set: Distilled's GCP and Workspace protocols set none either (the
  transport's default applies).
- Distilled has no long-running-operation helpers; `Operation` results are returned as
  data, as there.
- 17 TypeScript service files (408 ops: `apigeeregistry_v1`, `content_v2_1`,
  `datalabeling_v1beta1`, 13 `merchantapi_*_v1beta`, `mybusinessqanda_v1`) have no model
  in `.generated-specs`: they are stale outputs on Distilled's side, so there is nothing
  to generate from.
- `clients/gcp` is large (about 187 MB of Lua); `gen-diff gcp` takes about 2.5 minutes.
- The `credentials` client option takes a provider table; wrap a function with
  `creds.custom(fn)`.
