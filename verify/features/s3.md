# Amazon S3 (`clients/s3`, `distilled.s3`)

The Lua side of `@distilled.cloud/s3` (`../distilled/packages/s3`): the generated S3
client (112 operations) and the S3 helpers Distilled keeps in that package (presigning).

## Where things come from

- **Model**: Distilled has no S3 convert script. `packages/aws/scripts/convert.ts` writes
  `packages/aws/.generated-specs/s3.json` (AWS mirror + `packages/aws/patches/s3/`), and
  `packages/aws/scripts/generate.ts` writes `packages/s3/src/services/s3.ts` from it. Here:
  `verify/dl models sync aws` -> `models/aws/s3.json`, then
  `bin/distilled-lua generate --model models/aws/s3.json --provider providers/s3.lua --out clients/s3`.
- **Runtime**: the AWS protocol of task 17 (`lua/distilled/aws/`: restXml, endpoint rules,
  SigV4 through `distilled.sigv4`, httpChecksum, credentials chain, errors). S3-only parts
  are in `lua/distilled/s3/`.

## Sub-features

- **Addressing** (endpoint rules, `aws/endpoint.lua`): virtual-hosted
  `https://<bucket>.s3.<region>.<dnsSuffix>/<key>` for DNS-compatible buckets; path-style
  `https://s3.<region>.<dnsSuffix>/<bucket>/<key>` for buckets that are not (dots, upper
  case, shorter than 3); the partition's DNS suffix (`amazonaws.com.cn`, `amazonaws.eu`);
  a custom `endpoint` (MinIO, R2, LocalStack) is used as is with the bucket in the path.
  The region is the call's `region` input, the `region` option, then the credentials'.
- **Payload signing**: `x-amz-content-sha256: UNSIGNED-PAYLOAD` on every S3 request (the
  signer's S3 default), and for streaming-input operations (PutObject, UploadPart) on
  any service except those that rebuild the canonical request; S3 Control and Glacier
  sign the payload hash (`distilled.s3.payload`, same rules inline in `aws/protocol.lua`).
- **Checksums** (`aws.protocols#httpChecksum`, `distilled.s3.checksum`): Content-MD5 when
  the operation requires a checksum and no algorithm is chosen (DeleteObjects,
  PutBucket*, PutObjectTagging, ...); `ChecksumAlgorithm = "CRC32" | "CRC32C" | "SHA1" |
  "SHA256"` computes `x-amz-checksum-<alg>`; a checksum the caller gives is kept.
- **Bodies**: no streaming. PutObject/UploadPart take the whole body as a string (bytes
  exact); GetObject returns `Body` as a string. XML bodies follow restXml (xmlName,
  flattened lists, attributes, namespaces).
- **Errors**: `<Error><Code>..</Code><Message>..</Message></Error>` (and the wrapped
  `<ErrorResponse>` form) to the model's error classes with their extra fields
  (NoSuchBucket `BucketName`, InvalidObjectState `StorageClass`/`AccessTier`); an empty
  body (HEAD) by status (`NotFound`, `AccessDeniedException`, ...); S3's HTML 503 page to
  `SlowDown`; unknown codes to `UnknownAwsError`.
- **Region redirects**: a 301 `PermanentRedirect` is the typed error with `BucketRegion`
  (from `x-amz-bucket-region`), `Endpoint` and `Bucket`, as Distilled (which does not
  follow the redirect either). Retry the call with `region = err.BucketRegion`.
- **Pagination**: `list_objects_v2_pages` (ContinuationToken / NextContinuationToken,
  MaxKeys) and the other paginated operations (ListParts, ListBuckets, ...).
- **Presigning** (`distilled.s3.presign`, `distilled.s3`):
  - `presign.url{ url, service, ... }` (presignUrl), `presign.s3_url{ bucket, key,
    version_id?, content_type?, response_content_type?, endpoint?, ... }`
    (presignS3Url), `presign.post{ bucket, key, conditions?, fields?, ... }`
    (presignPost: a browser POST policy);
  - `s3.presign_s3_url(client, ...)`, `s3.presign_post(client, ...)`,
    `s3.presign_url(client, ...)`: the same with the client's credentials, region,
    endpoint and clock;
  - `s3.presign_request(client, "put_object", input, { expires_in })`
    (presignRequest / getSignedUrl): the request the call would send, signed into the
    URL; `x-amz-*` headers move to the query except SSE and checksum headers, the other
    headers come back in `headers` and must be sent verbatim; an input with a body is
    refused (InvalidInput).

## How a user reaches it

```lua
local S3 = require("s3")
local s3 = require("distilled.s3")
local client = S3.new({ region = "us-east-1", host = require("distilled.host.popen")() })
-- credentials: the default AWS chain (env, ~/.aws files, SSO, process, IMDS), or
--   credentials = require("distilled.aws.credentials").static{ access_key_id = ..., secret_access_key = ... }
-- S3-compatible stores: endpoint = "https://<account>.r2.cloudflarestorage.com", region = "auto"

assert(client:put_object({ Bucket = "b", Key = "hello.txt", Body = "Hello!", ContentType = "text/plain" }))
local obj = assert(client:get_object({ Bucket = "b", Key = "hello.txt" }))   -- obj.Body is the bytes
for page in client:list_objects_v2_pages({ Bucket = "b", Prefix = "logs/" }) do
  for _, o in ipairs(page.Contents or {}) do print(o.Key, o.Size) end
end
local _, err = client:get_object({ Bucket = "b", Key = "missing" })           -- err.tag == "NoSuchKey"
local url = assert(s3.presign_s3_url(client, { bucket = "b", key = "hello.txt", expires_in = 300 }))
local up = assert(s3.presign_request(client, "put_object",
  { Bucket = "b", Key = "a.png", ContentType = "image/png", ContentLength = 1024 }))
```

## Driving it with `dl`

- `verify/dl test s3_`:
  - `spec/s3_presign_spec.lua`: presignUrl / presignS3Url / presignPost against vectors
    from Distilled's presign.ts (`spec/golden/s3/presign.lua`, written by
    `node --conditions=bun --experimental-transform-types --no-warnings verify/lib/s3_vectors.mjs spec/golden/s3/presign.lua`),
    including the InvalidInput refusals, partitions, custom endpoints, session tokens.
  - `spec/s3_checksum_spec.lua`: digests against Distilled's hashers and node, the
    httpChecksum rules, the payload-signing rules.
  - `spec/s3_client_spec.lua`: the client-bound helpers and presign_request's header
    hoisting on a small AWS-shaped client.
  - `spec/s3_conform_spec.lua`: clients/s3 against Distilled's S3 client on
    `spec/golden/s3/conform.lua` (written by `verify/lib/s3_conform.mjs`): 47 signed
    requests (method, URL, every header including the SigV4 Authorization, body), 39
    response outcomes (values, typed errors with categories and fields), 3 ListObjectsV2
    page flows, 10 presigned requests.
- `verify/dl test --http s3_http`: `spec/s3_http_spec.lua` over a real transport
  against `dl serve` (path-style under a custom endpoint): binary PutObject/GetObject
  bytes, DeleteObjects XML + Content-MD5, NoSuchKey, a retried 503 SlowDown, two
  ListObjectsV2 pages, a presigned GET fetched without signing.
- `lua verify/lib/gen_check.lua $PWD $PWD/clients s3` (and luajit, `rex do`): every
  ref resolves, 111/112 operations build (SelectObjectContent's event stream is
  acknowledged unsupported). `dl gen-diff s3` does not apply: the model lives in
  `models/aws/`, not `models/s3/`.

## Intended differences from Distilled

- A custom endpoint's trailing `/` is dropped; Distilled sends `//bucket/key`.
- CRC32C, SHA1 and SHA256 checksums are computed; Distilled computes only CRC32 and
  MD5 and sends `x-amz-sdk-checksum-algorithm` alone otherwise (S3 refuses that).
- A string body gets no default `content-type: text/plain` (Distilled's `HttpBody.text`
  adds one, which S3 then stores as the object's type).
- `user-agent` is `distilled-lua/aws`, not `distilled-aws/1.0`.
- A wire error with no message has the tag as its message (distilled.errors' rule);
  Distilled's message is `""`.
- `presign.post` takes `fields` sorted by name when given as a map (a Lua table has no
  insertion order); pass a list of `{ name, value }` pairs to fix the order.
- `presign_request` signs by encoding the call (signed in headers) and re-signing it
  into the query; the result is the same request Distilled presigns.

## Gaps (task 17's runtime; `KNOWN` in spec/s3_conform_spec.lua, listed in STATUS.md)

A GetObject body that happens to be valid base64 is decoded; error categories from the
status are not emitted; GetBucketLocation's unwrapped output; a missing required label is
sent; empty bodies (`Body = ""`) are dropped both ways. Not ported: S3 Express session
auth (Distilled does not create sessions either), SigV4A (Multi-Region Access Points),
event streams (SelectObjectContent), aws-chunked streaming uploads.
